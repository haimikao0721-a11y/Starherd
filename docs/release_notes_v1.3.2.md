# 《牧星者 / STARHERD》v1.3.2

收尾补丁。多货舱必须全部送达，对接范围收小，第 1 章难度调回，并可以清空进度。

## 下载

源码在本仓库。安装包只含程序化素材。

## 修复

* 关卡里有几艘货舱，就要送达几艘。一艘进站不再算过关。
* 硬对接只比对接环大到 1.2 倍。再远不会自动对接。
* 第 1 章时限和燃料调回 1.3.1 之前的宽松程度。

## 新增

* 设置里可以重置游戏进度。点一次后再确认，通关、勋章和成绩会清空。音量和画质保留。

## 一、这是什么

《牧星者 / STARHERD》是一款**单机离线**的鼠标交互小游戏：你用鼠标拖动一个"引力井"，
靠真实的牛顿引力把货舱送进空间站对接环。软件不联网、不采集、不上传任何数据。

## 二、三种取得方式

| 方式 | 形态 | 是否需要安装 |
|---|---|---|
| 安装程序 | `Starherd_安装程序.exe` | 可选安装目录、创建桌面快捷方式与开始菜单项，含卸载入口 |
| 便携版 | `Starherd.exe` | 不需要：双击即运行，不写注册表 |
| 离线网页 | `Starherd_离线单文件版.html` | 不需要：双击用浏览器打开即可玩（无音乐下载入口） |

## 三、首次运行可能出现的安全提示（**正常现象**）

本软件**未购买代码签名证书**，因此 Windows 可能给出以下提示之一：

1. **SmartScreen**：「Windows 已保护你的电脑 / 未知发布者」
   → 点 **「更多信息」→「仍要运行」**。
2. **杀毒软件误报**：单文件打包（PyInstaller）的程序是杀软启发式规则的常见误报对象。
   若被拦截，请添加信任或改用「离线单文件版」。
3. **浏览器下载拦截**：部分浏览器会提示"此类文件可能有害"，属同一原因。

**如果你不放心运行 EXE**：可以直接使用 `Starherd_离线单文件版.html`，
它不需要任何运行环境，也不会写入除浏览器本地存储以外的任何位置。

## 四、数据与隐私

* **不联网**：游戏全部逻辑在本地运行，不含任何统计、遥测或广告组件。
* **写入位置**（仅两处）：
  * `%LOCALAPPDATA%\Starherd\save.json` —— 存档（章节解锁、最佳分、设置）
  * 若使用安装程序：安装目录（默认 `%LOCALAPPDATA%\Programs\Starherd`）与
    桌面/开始菜单快捷方式、HKCU 下的卸载登记项
* **卸载**：运行安装目录内的 `卸载 Starherd.bat`，或从「设置 → 应用 → 已安装的应用」卸载。
  便携版直接删除文件即可（存档如需清空，手动删除上面的 `save.json`）。

## 五、关于物理模拟的免责声明

游戏内的引力、轨道、潮汐撕裂、洛希极限、拉格朗日点、霍曼转移等**确实按真实公式计算**
（公式库见 `python/physics_ref.py`，自带 123 项自检），但为了可玩性做了**刻意的游戏化处理**：

* 使用无量纲单位（`G = 1`、恒星质量 `μ = 1`、1 RU = 128 px、1 TU = 1.6 s）；
* 采用 Plummer 软化、分步辛积分与自适应子步，**不是**高精度星历积分；
* 存在"引力井投影器""场强上限""算力/Δv 预算"等虚构机制。

**因此本软件仅用于娱乐与教学演示，不得用于任何真实的航天任务规划、导航或工程计算。**
作者不对因使用本软件而产生的任何直接或间接损失承担责任。

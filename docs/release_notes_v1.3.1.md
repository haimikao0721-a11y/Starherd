# 《牧星者 / STARHERD》v1.3.1

补丁。没通关不再解锁下一关，碎石雨不再越堆越卡，第 1 章没那么松。

## 下载

源码在本仓库。安装包只含程序化素材。

## 修复

* **下一关只在通关后解锁。** 失败或只是点进去，不会打开后面的关。
  旧存档里没有通关标记的成绩会清掉。
* **碎石雨**：同时最多 10 块，飞出作业区就消失，不再被辐射压加速到拖垮帧率。

## 难度

* 第 1 章时限收到大约 3 分钟。L1-2、L1-3 燃料更紧。L1-1 仍用来学对接。

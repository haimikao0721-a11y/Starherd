## 本版新增

### 关卡 12 → 20（新增第 5 章「星系串联」）

* **多段目标**：`objectives` 让"先送 A 站、泊位再切到 B 站"成为机制；HUD 显示「航段 N/M」
* `L5-1 双星摆渡`（A 站 → 伴星侧 B 站）
* `L5-2 引力弹弓`（低轨 → 主星高轨，用引力井甩摆换速度）
* `L5-3 三星摆渡`（三段航程）
* `L5-4 光帆航线`（辐射压当动力：低轨起航、高轨入坞）
* `L5-6 双星接力`（三段 + 宇宙风暴）
* `L5-7 碎石走廊`（碎石带 + 小行星雨，带一枚重舱硬闯）
* `L5-8 终局航段`（两段 + 太阳耀斑，光帆薄壳受 1.8 倍伤害）
* `L5-9 终章·双环`（两段航程 + 风暴，战役收尾）

### 随机事件 5 种（都可预警、可应对）

宇宙风暴（推进的力场锋面）· 极限救援（船体泄漏倒计时）· 太阳耀斑（薄壳/光帆重创）·
小行星雨 · 引力波掠过（潮汐四极踢）。
HUD 提前 3~6 秒预警；风暴与引力波的力**与 Tab 预测线共用同一函数**，看到的就是会发生的。

### 物理公式扩展（六项，每项都有可证伪的测试）

| 机制 | 检验方式 |
|---|---|
| **零速度曲线（Jacobi）** | 与地月系经典数表对照，误差 ~4e-5；临界值/层级/单调性共 19 项断言 |
| **奥伯特窗口提示** | 近星点加速最省 —— 用径向距离历史极小/极大判定 |
| **1PN 相对论进动** | 每圈进动与 `6πμ/(c²a(1−e²))` 吻合到 **0.5%**（6 项断言） |
| **霍曼 vs 双椭圆** | 阈值 **11.94** 与文献吻合；抛物线极限吻合 6 位小数（9 项断言） |
| **光帆关** | 辐射压实测抬轨：半径 6.24→5.15→7.50 |
| **Kozai-Lidov** | 临界倾角 **39.2315°** = arccos(√(3/5))；层级面板（见下方说明） |
| 转移方案对比 | 简报页直接给出"本关几何：霍曼 X · 双椭圆 Y → 推荐 Z" |

### 音乐 5 → 8 首

新增 **宇宙风暴**（G hijaz）· **救援倒计时**（A locrian）· **终章**（D ionian）；

### 难度标尺与预算放宽

`tools/difficulty_probe.py` 用内置 AI 实跑分档：**普通 4 · 困难 2 · 挑战 14**。
6 关的时限与燃料放宽（`fuel_scale`）——**只动预算，物理常量、几何、质量一律未动**。
> 口径说明：探针的自动驾驶**没有多段目标逻辑**，所以多段关卡一律被判"挑战"，
> 这反映 AI 的能力边界，不等同于人类难度（该说明随数据一起发布）。

## 修复

* 简报页的「Δv 预算」原先写死 `24 + 2.2×难度`，与实际公式 `(40+6×难度)×fuel_scale` 不符
* 关卡列表难度档位不显示（同名 CSS 类让补丁的存在性守卫误判）
* 主菜单联系区块不显示（锚点含模板收尾反引号，调用被插到模板外成了死代码）
* 宇宙风暴静默失效（运行时 level 逐字段手抄时漏抄 `events`）
* **1PN 的向量约定符号错误**——解析对照测试抓出来的：量级对到 0.5%，符号却是反的
* 音乐新曲不生效（`build_all_scores` 里写死的顺序表；谱面 schema 的 7 音约束）

## 已知限制（如实说明）

* **本作物理是二维的**，轨道无倾角字段 → **Kozai-Lidov 振荡不可能发生**。
  层级面板显示的是构型本身与这个诚实的结论，而不是编出来的振荡。
* `C_LIGHT = 30 RU/TU` 是**游戏单位**下为"进动可见"而调定的常数，不是 299792458。
* ZVC 面板是**两体近似**（主星 + 最重行星），其余天体与引力井会让 C 漂移 —— 界面已标注。
* 多段关卡的人类难度尚未校准（见上文口径说明）。
* 甩摆的"稳定阻尼"与"释放方向预测强化"未做（捕获面板已可用）。

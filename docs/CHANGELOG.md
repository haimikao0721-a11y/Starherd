# 更新日志 / CHANGELOG

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)：
**MAJOR** 不兼容变更 · **MINOR** 向后兼容的新功能 · **PATCH** 向后兼容的问题修复。

发布约定：**Release 只增不改** —— 每个版本打一次 tag、发一次 Release，附件一经发布不再覆盖；
修复一律进下一个版本，历史版本说明保持不变（如需更正，只补注说明）。

## [1.2.1] — 2026-10-13

补丁版：修一个发布件内部的诊断项，并补齐引力井甩摆的最后两块。

### 修复

* **打包版的 `assets_ok` 恒为 false**：`_compute_assets_ok()` 会先尝试构建期模块
  `assets_gen.verify_manifest()`，而它按源码树的相对路径校验素材；在 PyInstaller 冻结环境里
  这些路径指向解包临时目录，必然失配。改为**冻结环境直接走 fallback**（按 manifest 逐个查文件）。
  独立核对过 manifest 的每个 sha256/字节数（audio 17 / art 14 / music 8 项全部吻合），
  确认这是**诊断项的假警报**，不是素材损坏。

### 新增

* **甩摆稳定阻尼**：只对**已被引力井捕获**的货舱生效，且**只阻尼相对井的径向速度分量**
  （切向速度不动，不白送也不白扣能量）。实测径向振幅 1.2202 → 0.0695。
* **甩摆窗口提示**：捕获且接近**近井点**时提示「现在松手可获得最大抛射速度」——
  近井点用相对**井**的径向历史极小判定，与相对恒星的 Oberth 判定分开跟踪。
* **多段关卡的分档标注**：6 个多段关卡（L5-1/2/3/6/8/9）的档位带 `*`，
  简报页解释「AI 探针不会切换航段，该分档反映 AI 的能力边界」；`difficulty.json`
  的 `limited` 字段与探针脚本同步带上，以后每次重跑都自带。

## [1.2.0] — 2026-10-13

这一版把《牧星者》从 12 关扩到 **20 关**，并加入随机事件、多星串联与六项物理公式扩展。

### 新增

- **难度标尺（客观分档）**：新增 `tools/difficulty_probe.py`，用内置 AI 探针按
  "是否通关 / 用时占比 / 耗油占比 / 最近对接距离"把每关标成 **普通 / 困难 / 挑战**，
  产物写入 `assets/data/difficulty.json` 并在关卡列表与简报页显示档位。
  首轮分档：普通 4 · 困难 2 · 挑战 6。
- **放宽后半程预算（难但能过）**：6 关的 `par_time` 放宽、新增关卡级 `fuel_scale`
  （`fuelCapacity = (40 + 6×难度) × 系数`）。**只动预算，物理常量、几何、质量一律未动。**
- **随机事件系统（5 种）**：宇宙风暴（推进的力场锋面）· 极限救援（船体泄漏倒计时）·
  太阳耀斑（辐射脉冲，薄壳/光帆货舱重创）· 引力波掠过（潮汐四极踢）· 小行星雨。
  每种都有 **HUD 提前 3~6 秒预警**；风暴与引力波的力与 Tab 预测线**共用同一函数**
  （`eventAccelAt`），保证"预测线画的就是会发生的"。
- **多段目标（多星串联）**：关卡可选 `objectives: [{body, offset?, radius?, v_max?, label_zh?}]`；
  每成功对接一次航段 +1、泊位切换到下一个目标天体，HUD 显示"航段 N/M"。
  缺省时行为与旧版完全一致（12 关零影响，回归已证）。
- **新关卡 3 个（12 → 15）与第 5 章「星系串联」**：
  - `L5-1 双星摆渡`：A 站（主星侧）→ B 站（伴星侧）
  - `L5-2 引力弹弓`：B 站在主星高轨，直飞烧光预算 —— 用引力井甩摆在近井点松手换速度
  - `L5-3 三星摆渡`：三段航程 A → B → C（3 个货舱）
- **引力井甩摆（捕获面板）**：井是软化 1/r² 场，HUD 用**能量判据**
  `|v_rel| < sqrt(2·μ_eff/r)`（μ_eff 含外截止因子）判定捕获，并显示周期（Kepler 第三定律）、
  近井点、逃逸速度与"松手即沿当前速度方向甩出"。
- **联系方式铺开**：启动页 / 主菜单 / 结算页三处共用 `contactBlock()`（⭐ Star 号召 +
  复制邮箱 + 复制仓库），关于页、README、安装包使用说明同步加入邮箱。

### 修复

- 简报页显示的「Δv 预算」原先写死 `24 + 2.2×难度`，与实际公式
  `(40 + 6×难度) × fuel_scale` 不符 —— 等于给玩家错误信息，已改为一致。
- 关卡列表的难度档位标签不显示：根因是 `menu.ts` 里已有同名但不同用途的 `.lc-grade`
  （结算页评分徽章），补丁的存在性守卫误判导致插入被跳过。
- 主菜单联系区块不显示：锚点行结尾包含模板的收尾反引号，调用被插到模板之外成了死代码。
- 运行时 `LevelRuntime` 是**逐字段手抄**的，漏抄 `events` 导致宇宙风暴静默失效
  （`eta` 恒为初值）；已修并留注释警示。

### 工具

- `tools/difficulty_probe.py`（难度分档）· `tools/eventtest.ts`（事件力单元测试 7 项断言）·
  `tools/verify_objectives.py`（多段目标合成验收 6 项断言）
- 校验器泛化：关卡总数/难度覆盖由写死的 12 改为按实际关卡数推导（1..N），
  并新增关卡序号连续性检查。

### 已知未完成（如实记录）

- **音乐扩展**（事件段落 + 3 首新曲 + 新调式）未做。
- **物理公式扩展**（零速度曲线 / Oberth 提示 / 双椭圆对比 / Kozai-Lidov 显式机制 /
  1PN 进动 / 光帆关）未做。
- 关卡数 15/20：还差 5 关（事件关与更多甩摆关）。

## [1.1.0] - 2026-10-13

本次既有问题修复，也新增了玩家要求的性能设置面板，故为 MINOR 版本。

### 新增

* **性能设置面板**（暂停 →「设置」），四项全部即时生效并写入存档：
  * **渲染分辨率滑块** 35%~100%（另有「分辨率模式」自动/手动）——无头基准实测可省约 **35%** 帧时
  * **帧率上限** 不限 / 120 / 60 / 30；快捷键 `Y` 可循环切换
  * **物理步长** 120 Hz（精确）/ 60 Hz（弱机省 CPU）
* **「关于本作」界面**（主菜单入口）：制作者、GitHub 仓库、**一键去仓库点 Star**、个人主页、
  一键复制仓库地址、许可与素材声明
* **`tools/bench_settings.py`**：设置面板功能实测 + 改前/改后性能基准（可复现）
* **`tools/reset_save.py`**：查看/修复存档进度（默认只演练，写入前自动备份）
* **`tools/make_gifs.py`** 与 `docs/demo/`：用游戏自带 AI 录制的实机演示动画（4 个 GIF）
* **`docs/工程记录.md`**：完整开发工程记录（物理公式、关卡设计约束、探针的 11 项改进与 9 次证伪实验）

### 变更

* **游戏更名为《牧星者 / STARHERD》**（原名《拉格朗日信使 / LAGRANGE COURIER》）；
  存档目录随之改为 `%LOCALAPPDATA%\Starherd`，并内置**旧存档自动迁移**（解锁进度与最佳分不丢）
* **自动降级改为"先关特效、再降分辨率"**：泛光 → 色差 → 星场层数 → 场线 → 渲染分辨率。
  原先只降分辨率，弱机上效果有限
* **README 精简为展示型首页**（615 行 → 132 行），工程细节整体移入 `docs/工程记录.md`
* 开发与自动化验收默认**隔离存档目录**（`--dev` → `%TEMP%\starherd_dev`）

### 修复

* **打包后「背景音乐下载」整块消失**：`music_render.py` 用 `__file__.parent.parent` 定位素材，
  冻结后 `__file__` 指向 PyInstaller 临时解包目录 → 找不到 `assets/audio/*.json` → `/api/music` 返回空。
  改用项目自带的 `paths.assets_dir()`；并把 `music_render` / `wave` 加进构建的 `HIDDEN_IMPORTS`
* **刚进游戏时背景音乐有巨大噪音**：`updateAudioParams()` 在主菜单也生效，而主菜单播放的是
  吸引模式（AI 自己玩），AI 把燃料烧到 0 → 触发最高严重度的低频心跳（每 0.62 s 一记重击）。
  现改为心跳/警报只在 `screen === 'play' && !attract` 时生效
* **自动化验收污染玩家存档**：`tools/verify_ui.py` 以真人路径驱动真实 UI，
  跑一次等于替玩家玩了一关（实测把前 6 关解锁了）。已通过存档目录隔离修复
* **构建产物被占用导致 EXE 未被重建**：PyInstaller 打包成功后复制产物遇到
  `PermissionError`（残留的 onefile 子进程锁住文件），构建脚本却继续报"完成"。
  现要求构建后**核对包内源码**来证明产物确实更新

## [1.0.0] - 2026-10-12

首个公开发布。

### 新增

* **12 关 / 4 章**，覆盖 5 类多体系统：单恒星、行星系·双卫星、双星 + L4/L5 稳定岛、
  黑洞 + 恒星双星、层级三合星
* **4 种货舱变体**：标准 / 重型 / 易碎 / 光帆（质量、半径、结构强度、受辐射压截面各不相同）
* **真实公式层**：Plummer 软化引力、速度 Verlet 辛积分 + 自适应子步、层级轨道（patched conic）、
  洛希极限与潮汐撕裂半径、Hill 球、拉格朗日点、辐射压、星风脉冲、星云二次阻力、
  引力时间膨胀、霍曼转移、齐奥尔科夫斯基方程；公式库自带 **123 项自检**
* **关卡校验器**：9 类判据 + 12 关构造性可行性证明
* **自动驾驶能力下限探针**：内置 AI 自己会玩，用于验证关卡可被通过（6/12 有自动通关记录）
* **程序化素材管线**：17 张美术 + 17 个音效 + 5 首音乐全部由 Python 生成/合成，**零第三方素材**
* **三种交付形态**：便携单文件 EXE、可选目录安装程序（含桌面快捷方式与卸载）、离线单文件网页
* **背景音乐下载**（EXE / 网页模式的暂停页）与 5 首正式曲名

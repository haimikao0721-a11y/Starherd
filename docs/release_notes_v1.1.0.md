> **版本说明**：修复了 v1.0.0 反馈到的三个问题（音乐下载消失、进游戏噪音、卡顿与设置无效），
> 并新增玩家要求的性能设置面板。完整变更见 [CHANGELOG](https://github.com/haimikao0721-a11y/Starherd/blob/main/docs/CHANGELOG.md)。

## 本版修复与新增

**修复**

* **背景音乐下载整块消失**（打包后才会复现：素材路径在冻结环境下解析错误）
* **刚进游戏时背景音乐有巨大噪音**（主菜单待机时误触发低频心跳层）
* **卡顿与设置无效**（自动降级原先只降分辨率，弱机上收效有限）

**新增**

* **性能设置面板**（暂停 →「设置」，即时生效）：
  * **渲染分辨率滑块** 35%~100%（自动/手动）—— 实测可省约 **35%** 帧时
  * **帧率上限** 不限 / 120 / 60 / 30（快捷键 `Y` 循环）
  * **物理步长** 120 Hz（精确）/ 60 Hz（弱机省 CPU）
* 「关于本作」界面：制作者 / 仓库 / **一键点 Star** / 个人主页

### ⚠️ 首次运行提示（正常现象）

程序**未做数字签名**，因此可能遇到：

* **SmartScreen**：「Windows 已保护你的电脑 / 未知发布者」→ 点 **「更多信息」→「仍要运行」**
* **杀毒软件误报**：单文件打包程序是启发式规则的常见误报对象；如不放心请改用离线单文件版

**不需要安装 Python 或任何运行环境**；Win10 若缺少 WebView2，程序会自动回退到 Edge `--app` 模式。

### 卡顿的话

暂停 →「设置」→ 先试把 **渲染分辨率** 拉到 50%，仍卡再切 **物理步长 60 Hz**。

## 内容

* **12 关 / 4 章**，覆盖 5 类多体系统：单恒星、行星系·双卫星、双星 + L4/L5 稳定岛、黑洞 + 恒星、层级三合星
* **4 种货舱变体**（标准 / 重型 / 易碎 / 光帆）
* **真实公式层**：Plummer 软化引力、速度 Verlet 辛积分、层级轨道（patched conic）、
  洛希极限与潮汐撕裂半径、Hill 球、拉格朗日点、辐射压、星风脉冲、星云阻力、引力时间膨胀
* **程序化素材**：17 张美术 + 17 个音效 + 5 首音乐，**零第三方素材**（生成器与种子都在仓库里）
* **背景音乐可在游戏内下载**（EXE/网页模式：暂停页 →「背景音乐下载」）

## 操作

| 操作 | 说明 |
|---|---|
| 左键拖动 | 引力井（吸引） |
| 右键拖动 | 斥力 |
| 滚轮 | 场强 ｜ **Alt+滚轮** 缩放视野 ｜ `0` 复位 |
| 空格 | 慢动作（×0.25） ｜ **`T`** 时间加速 1×→2×→4× ｜ **`Y`** 帧率上限 |
| `Tab` / `G` / `F` | 预测轨道 ｜ 引力场线 ｜ 速度矢量 |
| `R` / `Esc` / `H` | 重试本关 ｜ 暂停（含设置） ｜ 帮助 |

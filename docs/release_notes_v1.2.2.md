# 《牧星者 / STARHERD》v1.2.2

补丁版。补上**多段航段的结算支持**（此前只做了 HUD 里的航段提示），并修正过时文档。
关卡、音乐与物理机制与 v1.2.1 相同（20 关 / 5 章 / 8 首曲子 / 5 种事件 / 六项物理机制）。

## 修复

* **结算页没有航段信息**：多段关卡（如 L5-9 终章·双环）打完后，结算页现在会显示
  「航段 / LEGS」一行：多段关卡显示 `N/N · 全部泊位已交付`，单段关卡不显示。
  实测：L5-9（2 段）出现该行，L1-1（1 段）不出现。
* **关卡列表的 `*` 档位不渲染**：档位标签现在正确显示 普通 / 困难 / **挑战\***，
  其中带 `*` 的表示该关有多个航段、而内置 AI 探针不会切换航段，档位仅供参考。

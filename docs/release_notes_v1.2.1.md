# 《牧星者 / STARHERD》v1.2.1

补丁版。这一版修了一个**发布件内部诊断项的假警报**，并把**引力井甩摆**补齐到可用状态。
关卡、音乐与物理机制与 v1.2.0 相同（20 关 / 5 章 / 8 首曲子 / 5 种事件 / 六项物理机制）。

## 三种交付形态

| 下载 | 说明 |
|---|---|
| **Starherd.exe** | 便携版，双击即玩 |
| **Starherd_Setup.exe** | 安装程序（可选目录、快捷方式、可卸载） |
| **Starherd_offline.html** | 离线单文件网页版 |

## 修复

* **打包版 `/api/health` 的 `assets_ok` 恒为 false**：内部校验误用了构建期模块
  `assets_gen.verify_manifest()`，它按源码树相对路径找文件，在冻结环境里必然失配。
  改为冻结环境直接按 manifest 逐个核对。
  > 已独立核对 manifest 的每个 sha256 与字节数（audio 17 / art 14 / music 8 项全部吻合），
  > 所以这是**诊断项的假警报**——素材本身在 v1.2.0 里就是好的
  >（实测 20 关、8 首曲子、新增曲目 WAV 下载均正常）。

## 新增

* **甩摆稳定阻尼**：货舱被引力井捕获后，径向摆动会被轻微压住（切向速度不动，
  不白送也不白扣燃料）。实测径向振幅 **1.2202 → 0.0695**，货舱稳定在近圆轨道上，
  松手即可**可预期**地甩出。
* **甩摆窗口提示**：捕获且接近近井点时显示「⚑ 甩摆窗口：现在松手可获得最大抛射速度」。
  近井点按**相对引力井**的径向历史极小判定（与相对恒星的奥伯特判定分开跟踪）。
* **多段关卡的分档标注**：6 个多段关卡的档位带 `*`，简报页给出解释 ——
  内置 AI 探针不会切换航段，因此这些"挑战"反映的是 **AI 的能力边界**，
  不等同于人类难度。

# 《牧星者 / STARHERD》v1.3.0

新功能版。全通关结尾与两枚勋章、带钢琴的主菜单慢流行，以及针对内测「比较卡」的画质调整。
音乐全部由本项目合成。

## 下载

源码在本仓库。安装包只含程序化素材，不含外部录音。

## 新增

* **航线闭合**：20 关全部通关后，主菜单和结算页可以打开。每关播放对接前约 7 秒的操作记录；
  这个版本之前就通关的关卡只有成绩卡。
* 结尾播放本项目的主菜单曲子，然后颁发 **牧星者**。
  20 关最佳成绩都是 S 时，再颁发 **无瑕航线**。
* **主菜单**改为安静的慢流行（C 大调 I–V–vi–IV）。主音是钢琴。关卡配乐仍是项目自己的谱面。
* **启动画面**换成像素头图 GIF：字会闪，星星会亮，货舱和引力井偶尔动一下。

## 修复

* 主菜单不再因为待机演示自己通关而响起号角，也不再循环推进器嘶声。
* 音乐和音效滑块现在会跟着变响，拖动是渐变。设置页和暂停页都可以下载背景音乐。
* 帧率：新存档默认中画质；像素上限 1.25 倍；菜单背后的演示减轻；对局持续超帧会自动降档并记住。

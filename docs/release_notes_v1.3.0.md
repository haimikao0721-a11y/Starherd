# 《牧星者 / STARHERD》v1.3.0

新功能版。全通关结尾与两枚勋章、主菜单慢流行，以及针对内测「比较卡」的画质调整。

## 下载

源码在本仓库。安装包不附带第三方录音。
若要在本机听到全通关结尾的《Hopes and Dreams》，把你自己拥有的文件放到
`assets/audio/third_party/hopes_and_dreams.m4a`（该文件不进 Git，也不进安装包）。

## 新增

* **航线闭合**：20 关全部通关后，主菜单和结算页可以打开。每关播放对接前约 7 秒的操作记录；
  这个版本之前就通关的关卡只有成绩卡。
* 曲子放一遍 **Hopes and Dreams**（Toby Fox，《Undertale》），然后颁发 **牧星者**。
  20 关最佳成绩都是 S 时，再颁发 **无瑕航线**。最后署原作者。
* **主菜单**改为安静的慢流行（C 大调 I–V–vi–IV）。关卡配乐仍是项目自己的谱面。

## 修复

* 主菜单不再因为待机演示自己通关而响起号角，也不再循环推进器嘶声。
* 帧率：新存档默认中画质；像素上限 1.25 倍；菜单背后的演示减轻；对局持续超帧会自动降档并记住。
